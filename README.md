# EdgeRoute CDN Releases

EdgeRoute CDN 官方版本发布仓库，提供各组件的安装包、更新文件及版本说明。

EdgeRoute 是一套面向网站加速与安全防护的 CDN 管理系统，包含管理端、API 服务、边缘节点和用户端，支持站点管理、缓存加速、HTTPS 证书、安全防护及流量分析。

官网： https://edgeroute.org/
许可证：https://license.edgeroute.org/
推荐：一键安装 curl --proto '=https' --tlsv1.2 -fsSL https://edgeroute.org/install.sh | sudo bash
## 下载与更新

请前往本仓库的 **Releases** 页面下载正式发布版本。

- 首次安装：选择对应组件与系统架构的安装包。
- 版本升级：先阅读该版本的发布说明，确认升级顺序及兼容要求。
- 自动更新：已配置本仓库更新源的组件，可通过系统支持的更新入口检查新版本。

请下载 Release 附件中的正式安装包。GitHub 自动生成的 `Source code` 压缩包不是产品安装包。

## 安全校验

安装或更新前，请核对文件的 SHA256，并使用已信任的发布公钥验证签名。

SHA256 用于检查文件是否完整，数字签名用于验证发布来源。首次使用公钥时，请通过可信渠道核对公钥指纹，不要仅依赖同一下载位置提供的公钥。

## 升级提醒

- 升级前备份数据库、运行配置及必要的数据目录。
- 按发布说明要求的组件顺序进行升级。
- 保留节点待上报队列及相关状态文件，避免影响流量统计。
- 升级后检查服务状态、组件版本及核心功能。
